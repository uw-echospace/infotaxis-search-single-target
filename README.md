# Infotaxis for echolocation-based target search

This repository contains code associated with the following paper:

**Modeling echolocation as an active pursuit of information via infotaxis**

Authors: [Wu-Jung Lee](https://uw-echospace.github.io/author/wu-jung-lee/) ([@leewujung](https://github.com/leewujung)), John R. Buck, and Peter L. Tyack


## Repo structure
- [`src/infotaxis`](./src/infotaxis/): Core model code for an echolocating infotaxis agent searching for a single target
- [`notebooks`](./notebooks/): Notebooks to generate figures presented in the paper
    - [`notebooks/data_prep`](./notebooks/data_prep/): Notebooks to prepare data for use in the plotting notebooks
- [`figs`](./figs/): Figures generated by the notebooks presented in the paper.
- [`scripts`](./scripts/): Code to simulations on an HPC via slurm
- [`simulations`](./simulations/): Simulation outputs or intermediate data products. Note that the bulk of simulation outputs are stored as GitHub release assets due to the file size.


## Documentation
- To generate all data needed for creating Figs. 4, 5, 6B, S1, S4/S5:
    - Download all release assets (the `*.zip` files [here](https://github.com/uw-echospace/infotaxis-search-single-target/releases/tag/v0.1.0a1))
    - Extract the content of all `*.zip` files under the `simulations` folder
    - Follow the steps described in [simulation and data preparation steps before plotting](./docs/simulation_data_prep.md) to prepare data for plotting
