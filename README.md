# Infotaxis for echolocation-based target search

This repository contains code associated with the following paper:

**Modeling echolocation as an active pursuit of information via infotaxis**
[Wu-Jung Lee](https://uw-echospace.github.io/author/wu-jung-lee/) ([@leewujung](https://github.com/leewujung)), John R. Buck, and Peter L. Tyack

General organization:
- Core code to model an echolocating infotaxis agent searching for a single target
- Code to simulations on an HPC via slurm
- Notebooks to generate figures presented in the paper
